## 图片提示词（image_prompt）——切换到「摄影师」视角

- **片头首镜必须有一张构图参考图**：为本集第一条分镜从 0 秒开始的首镜选图，即使没有上一镜可承接。用同一机位交代场景的地标和空间层次、每个出镜人物相对于场景的站位与朝向、关键道具或商品在哪、由谁拿、与人和场景的比例及遮挡。以首镜实际出场的内容为准，不硬加人物或物件。
- **后续镜头按需选图**：先编排完整的 `video_prompt.action`，再判断相邻镜头是否有同一场景、主要人物是否延续，以及是否需要固定人、景、物的关系。没有可延续的场景、切到无关场景、主要人物变化过大或只是独立插入镜头时跳过；同场同人连续动作或轻微换机位时不逐段配图。按本分镜 `video_prompt.action` 内实际时间段的顺序，从 1 开始把选中序号写入 `reference_image_shots`，例如 `[1]`。不要填写时间标签，程序会从实际时间轴取值。都不需要时写 `reference_image_shots: []` 和 `image_prompt: null`。`image_prompt` 只为选中的镜头提供构图基准，未选的镜头只写视频提示词。

- **image_prompt.scene**：这段文字将直接生成一张静态图。把景别、机位、主体（姿态 / 表情 / 服装）、环境、光线和氛围全部写进正文，只描述这一帧，使用连贯的叙述句。原文若是回忆 / 闪回 / 心理活动，将其改编为此刻可见的载体——人物神态、手中物件、环境痕迹，画面里只保留一个时空。画面元素（材质、装束、道具质感、环境年代特征）须贴合上方 `<style>` 块定义的风格基调，避免与风格相冲的元素混入（例如赛博朋克风下不出现榻榻米，国风水墨下不出现霓虹屏）。画面里出现的已登记资产（角色 / 场景 / 道具 / 商品）用 `@[登记名]` 指认（衍生形态写 `@[角色/衍生]`），并把同一名字写进本条目的引用字段。正文始终保留 `@[登记名]`，参考图槽位清单由系统单独维护；未登记或未写进引用字段的名字只会按原文发送；未登记的物件直接写名，不加 `@[]`。
   正例：「@[林清]坐在窗边木桌前，左手撑着下巴，目光落在桌上一封拆开的信纸上；桌面摊着信封与一只褪色的怀表。半边脸笼在右侧落地窗逆光的蓝灰色阴影里，雨丝拍在木格窗棂，玻璃凝着细小水珠。」——主体、环境、光线、氛围各有一笔，全程叙述句；已登记的林清用 `@[]` 指认，未登记的怀表直接写名。
   正例（原文是回忆）：原文「她想起亡母临终的嘱托」→「沈茹跪坐在灵位前，指尖抵着一串磨得发亮的佛珠，眼睑低垂。案上白烛烧过半，烛泪层层堆叠，烛焰在她侧脸投下摇晃的暖橙光斑；一缕香灰无声落在青砖上。」——回忆的分量由此刻的神态与旧物承载，画面只有一个时空。
   反例（跑偏）：「林清陷入了多年前那个绝望的雨夜，画面基调：忧郁。光影设定：冷调。」——「多年前的雨夜」不在此刻画面上；「忧郁 / 冷调」是抽象标签，不是可见细节。
   反例（过短）：「林清坐在窗边发呆。」——缺少环境元素、光线方向、氛围细节，至少应覆盖主体 / 环境 / 光线 / 氛围中三层。- **人物与手机的视觉转译**：不要把“低头玩手机”“拿着手机”“站得自然”“靠近人物”等概括性或口语化描述直接交给图像模型。先将其转成单帧可见的几何关系，写入 `image_prompt.scene`：人物的支撑面和重心（站立或坐姿、髋部落点、承重腿）、躯干与头部朝向、肩肘腕和膝踝弯曲、双手分工、手指与物件接触点、视线落点；手机写明由哪只手持握、相对身体的锚点（胸前、腹前、耳侧或大腿上方）、在画面左中右和前后景、屏幕或背面朝向镜头、倾角、距离、露出范围和遮挡。不要只写“姿势自然”“手机在手里”“看手机”。例如：“人物坐在椅面，髋部落在座面中央，左脚支地承重，右膝抬高；右手握手机在胸前，手机底边距下巴约一掌，屏幕朝向镜头并向上倾斜约 20°，左手食指触碰屏幕右下角，视线落在屏幕上。” 手机背面朝向镜头时，明确写出背壳和摄像头可见，屏幕被手掌或机身遮挡。
- **素材关系**：用 `@[登记名]` 写清每个引用素材在成图里负责什么，以及如何与其他素材结合：谁在什么场景、坐在哪或靠着什么、谁拿哪个道具、用哪只手、商品露出多少。角色参考图只定外形，场景图定空间，道具和商品图定物件外观；最终姿态、动作、站位及遮挡由本镜正文指定。参考图槽位由系统根据实际请求维护，正文不要手写槽位编号。
- **站位与比例**：先由文本 Agent 根据参考素材、已知商品尺寸和本镜描述，推理出可执行的画面比例关系，再把结论写进 `image_prompt.scene`。图像模型只执行正文已写明的关系，不负责推理主体大小、位置、距离或接触方式。以观众视角写出每位人物、每件可见道具和商品的左中右、前中后景、朝向、可见面与遮挡。覆盖三组尺度：人和景（人物占画幅高度、取景裁切、与门窗或家具的相对高度及距离）、人和物（物件相对手掌或身体的大小、握持点及接触位置）、景和物（物件相对台面、地面或摆放空间的面积、距离与间隙）。逐项写成具体关系，例如“商品约一掌宽”“人物从头到膝约占画面高度一半”“商品露出三分之一”“物件距台面边缘约半掌”，并写清支撑、接触、遮挡和受力方向。结合参考素材及已知商品尺寸，区分实际大小和远近造成的画面大小；未知尺寸使用身体部位、常见物件或画幅比例作相对标尺，不杜撰绝对尺寸，也不要只写“比例合理”“大小自然”等抽象结论。
- **姿态与正反面**：逐人写重心、身体与头部朝向、视线、手脚弯曲、持物用手和受力点；场景写地面坡度、门窗和家具朝向、进深及动线；物件写正反面、垂直或倾斜角度、落点、支撑、遮挡和可见范围。屏幕显示只出现在屏幕朝向镜头且可见的部分；手机背壳朝镜头时只显示背壳和摄像头。须交代低电量又要拍到屏幕时，调整人物握持角度或机位，让屏幕实际可见。
- **同一空间**：明确机位高度与视角，让站立或坐姿有合理的支撑，人物、道具、背景共享同一透视、光源和投影方向。多图用于合成一张连贯画面，不分别复制每张图的取景、背景或打光。
  构图示例：「以略低于眼平的机位拍中远景。@[阿岑]在画面左侧中景，坐在@[露营椅]上，头到膝约占画面高度一半；@[小满]在画面右侧、同一深度，侧身望向阿岑。@[充电宝]约一掌宽，从阿岑右侧夹克口袋露出上三分之一。两人后方是@[山坡草地]的低矮山脊，右后侧夕阳同时勾亮人物轮廓与口袋露出的商品边缘。」
- **正面描述**：只写成图应呈现的细节，不另写负面提示词列表。
- **镜头、光线与氛围**：在正文写具体景别、光源、方向和色温，使用可观察的环境细节，例如「平视中景，左侧窗户透入暖黄色晨光，尘埃在光柱里翻飞」，不要另写构图字段。
