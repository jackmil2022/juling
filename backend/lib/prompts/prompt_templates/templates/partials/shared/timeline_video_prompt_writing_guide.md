# 时间轴式视频提示词（强制）

视频提示词必须从 `0s` 连续覆盖剧情编排时长，不重叠、不留空档。时间点可精确到 0.5 秒，例如 `[0s-1.5s]`；只在动作、台词或构图需要时细分，不机械拆段。生成请求按模型有效时长提交；短于 4 秒的内容只在原动作结束后定格补尾，不拉长剧情，不补台词。

- **参考生视频正文（`unit.text`）**：每段依次写时间范围、`镜头：`、`转场：`、`画面/动作：`、`特效：`、`声音：`、`台词：`，每项独占一行，段间空一行。正文用项目语言；镜头和转场的字段名写 `镜头` / `转场` 或 `Shot` / `Transition`。
- **分镜 `video_prompt`**：在正文（结构化时为 `action`）逐段分行写「镜头：」「转场：」「画面/动作：」「特效：」「声音：」「台词：」。每段写清景别、机位、焦点和运镜，以及环境声和动作音效，不另写全局运镜或音效字段。角色台词沿用该模式的规定字段，`action` 在对应时间段标明说话人及台词顺序。分镜参考图只作为相应时间段的构图参考，不作为首尾帧；无已生成的分镜参考图时，生成端按需使用资产图。请把本镜可见的每个角色和场景写入引用字段；商品仅引用登记的 AI 商品图。
- **正面描述**：写成片应呈现的构图、动作轨迹、视线、表情、对白语气和画内声音。已绑定的素材要在正文中用 `@[登记名]` 指明用途，例如 `@[阿岑]` 确定人物外形；参考视频和音频的用途写入对应字段或声明。正文不写图号，素材槽位由系统按实际提交顺序维护。保留用户已有的参考视频声明，编写时不得凭空声明。
- **镜头**：逐段写景别、机位和角度、构图与焦点、运镜。比如“侧面近景，平视，人物居左，焦点从手移到脸，缓慢推近”。换机位或剪切到另一画面时，从切换的秒数另起一段。同一镜头可因动作或台词变化分段。
- **转场**：写本段起点如何接上一段，明确切换方式、承接的动作或视线。硬切、动作匹配、视线切等按情节选择；同一镜头写“同镜延续”并说明承接状态；全片首段写开场方式。若剧情要求无缝续接，首段要从上一镜结束时人物与物件的姿态、位置、运动方向写起，在该状态基础上扩展本镜的新动作，不重演上一镜；末段写清留给下一镜的动作、视线或画面落点。邻镜上下文仅用于创作，不代表邻镜视频已占用槽位。镜头和转场不要写“无”。
- **画面 / 动作**：每个时间段都用 `@[登记名]` 点名实际在场且参与动作的角色、所在场景及用到的登记物件；不要只写“他”“那个人”“同上”。先把人物的口语化动作转成模型可执行的起始状态、运动路径和结束状态，写清支撑面、重心、关节方向、手指接触点、视线落点，以及手机相对身体的高度、移动方向、屏幕或背面朝向镜头、倾角和遮挡变化。不要只写“拿手机”“看手机”“手机在手里”。例如「@[阿岑]在@[山坡草地]左侧盘腿坐稳，左脚收在身下，右手从右侧大腿上方将@[手机]举到胸前，手腕向内旋转使屏幕朝向镜头，手机底边距下巴约一掌，左手食指触碰屏幕右下角，视线跟随手机上移；@[小满]转头看向阿岑的右手」。写清每人的起止状态、位置、动作方向、交互对象、谁持物、谁在说话，以及镜头切换后如何连续。没有人物的镜头点名场景与主要物件，不硬加角色。特效写可观察效果，没有写“无”。
- **声音**：只写画内声音与说话声，例如脚步、衣料摩擦、开门声、碰撞声、环境声；不要写 BGM、配乐、画外音或旁白。没有声音写“无”。
- **台词 / 旁白**：参考生视频正文继续使用 `@[角色]{台词}` 表示角色说话、`{台词}` 表示画外音；有 `dialogue` 字段的结构化提示词使用 `speaker` / `line` 字段。台词必须逐字保留，不能改写、拆词或替换说话人；没有台词写“无”。广告 / 短片的 `voiceover_text`、旁白 / 解说的 `novel_text`、剧情演绎 `utterances` 中的 `voiceover` 会由系统统一注入最终视频提示词的 `Voiceover` 字段，旁白须在标注时段内读完，不延续到定格补帧段。不要复制到 `dialogue`，也不要在视频正文重复写旁白。
- 时间段数量按动作复杂度决定，但必须让读者能回答“第几秒到第几秒发生什么、有什么特效、听到什么声音、谁说了什么”。不要用“随后”“接着”代替时间范围。

示例（8 秒视频单元）：

```
[0s-2s]
镜头：侧面平视中景，人物居左，门在右侧，焦点落在人物脸上，机位固定。
转场：直接开场，人物已站在桌边。
画面/动作：@[角色A] 抬头望向门口，手指停在 @[道具A] 上。
特效：窗外光斑缓慢移动。
声音：远处风声、指尖触碰桌面的轻响。
台词：无。

[2s-5s]
镜头：侧面平视中景，顺着人物走向门口平移跟拍并缓慢推近，焦点移到门把手上。
转场：同镜延续，接住人物望向门口的视线，再跟随转身。
画面/动作：@[角色A] 转身走向 @[场景A] 的门口，手伸到门把手上。
特效：门缝透出一束光，轻微动态模糊。
声音：脚步声、门轴轻响。
台词：@[角色A]{我知道你来了。}

[5s-8s]
镜头：从人物肩后拍门口的近景，平视，门框构图，焦点从门边移到来人脸上，机位固定。
转场：5 秒处动作匹配切，接住上段转动门把手的动作。
画面/动作：门打开，@[角色B] 停在门外，@[角色A] 与其对视。
特效：光束扩大，空气中浮尘清晰可见。
声音：门完全打开的摩擦声、室内环境声。
台词：无。
```
